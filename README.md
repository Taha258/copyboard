# CopyBoard — Premium High-Converting Landing Page ⚡

A modern, high-performance landing page built with pure HTML5, Vanilla CSS3, and JavaScript, styled in a sleek dark theme with vibrant gold/yellow accents.

---

## ✨ Features

- 🟡 **Floating Pill Navbar** — Glassmorphic floating nav with high-res brand logo & smooth micro-tilt.
- 🚀 **Hero Section** — Technical golden plus-cross `(+)` texture background, 3D floating decorative elements, social proof, and interactive card tilt.
- ⚡ **Dual-Direction Ticker Strips** — Infinite animated marquees scrolling in opposite directions.
- ⭐ **Auto-Scrolling Testimonials Masonry** — Multi-speed auto-scrolling columns with pause-on-hover & interactive pop-up avatar zoom.
- 💎 **3D Pricing Section** — Interactive 3D tilt cards, monthly/annual toggle with flip animations, and mouse-following spotlight effect.
- 📅 **Interactive Booking Widget** — Live digital clock, real-time analog clock with smooth continuous hands, month navigator, and time slot picker.
- ❓ **FAQs Accordion** — Modern 2-column layout with question badges and smooth accordion expand/collapse.
- 🌟 **Dynamic Footer Banner** — 60FPS vector SVG brand banner with interactive mouse-follow spotlight illumination.
- 🔝 **Scroll-To-Top Tracker** — Fixed bottom-left button with a circular SVG progress ring indicating page scroll percentage.

---

## 🛠️ Tech Stack

- **HTML5** (Semantic structure, accessibility)
- **Vanilla CSS3** (Custom properties, keyframes, glassmorphism, responsive grid & flexbox)
- **Vanilla JavaScript (ES6+)** (High-performance DOM interactions, requestAnimationFrame, lerp interpolation)

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/copyboard.git
   cd copyboard
   ```

2. Open with any local server (or live server):
   ```bash
   npx serve .
   ```
   or simply open `index.html` directly in your browser.
